# Atelier Entrega

Sistema de entrega de fotos para clientes: galerias privadas, pastas por momento, senha e download em ZIP.

## Como usar

1. Abra o site
2. Entre em **Área do fotógrafo** com o PIN `garrido2026`
3. Crie uma galeria, organize pastas e envie as fotos
4. Copie o link e mande no WhatsApp

Galerias de demonstração:

- `/g/casamento-ana-pedro` — senha `anaepedro`
- `/g/ensaio-familia-oliveira` — senha `oliveira`
